🚀 Quiero agregar mi juego

La página de juegos es un proyecto colaborativo. Para agregar tu juego no vas a modificar directamente el repositorio principal.

⚠️ IMPORTANTE

Primero tenés que hacer un Fork. Después vas a trabajar sobre tu propia copia del proyecto y finalmente vas a enviar un Pull Request.

1. Hacé un Fork

Entrá al repositorio principal en GitHub y presioná el botón Fork.

Esto crea una copia del proyecto en tu propia cuenta de GitHub.

2. Cloná tu repositorio

Copiá la URL de tu Fork y abrí una terminal.

git clone https://github.com/TU-USUARIO/juegojs.git

3. Entrá en la carpeta

cd juegosjs

4. Agregá tu juego

Creá una carpeta para tu juego dentro de juegosjs/.

Por ejemplo:

juegosjs/
└── snake-juan/
    ├── index.html
    ├── style.css
    └── script.js

También podés utilizar la estructura de tu juego original.

5. Modificá la página principal

Abrí el archivo index.html y buscá una tarjeta que diga "Juego disponible".

Reemplazala con los datos de tu juego.

<div class="card">

    <div class="numero">01</div>

    <h3>Snake</h3>

    <p>Alumno/a: Juan Pérez</p>

    <a href="juegos/snake-juan/" class="boton">
        JUGAR
    </a>

</div>

6. Comprobá que funcione

Abrí la página en tu navegador y comprobá que tu juego se pueda abrir correctamente.

Revisá también que no hayas roto las otras tarjetas.

7. Revisá los cambios

Desde la terminal podés utilizar:

git status

Este comando muestra qué archivos fueron modificados.

8. Prepará los archivos

git add .

9. Creá un Commit

Guardá tus cambios en Git con un mensaje que explique qué hiciste. 

git commit -m "Agrego mi juego"

10. Subí los cambios a GitHub

git push

11. Creá un Pull Request

Volvé a GitHub.

GitHub debería mostrarte la posibilidad de crear un Pull Request.

El Pull Request es una propuesta para incorporar tus cambios al repositorio principal.

12. Esperá la revisión

El profesor va a revisar tu Pull Request.

Puede aceptarlo o pedirte algún cambio.

Si todo está correcto, tu juego aparecerá en la página.

💻 Comandos básicos

# Descargar un repositorio
git clone URL

# Entrar en la carpeta
cd nombre-del-proyecto

# Ver los cambios
git status

# Preparar los cambios
git add .

# Crear un commit
git commit -m "Descripción del cambio"

# Subir los cambios
git push
💡 ¿Querés hacer algo más?

También podés proponer mejoras para esta página.

Por ejemplo: cambiar los colores, mejorar las tarjetas, agregar un buscador, agregar categorías, crear un modo oscuro o cualquier otra idea.

Las mejoras también se hacen mediante Fork + Commit + Pull Request.
